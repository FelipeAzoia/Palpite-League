# Requisitos não funcionais

## RNF01 — Segurança dos dados

O sistema deverá proteger os dados pessoais, financeiros, credenciais e informações das apostas de todos os usuários durante toda a utilização da plataforma.

## RNF02 — Integridade das informações

O sistema deverá manter a integridade e consistência dos dados das ligas, participantes, pagamentos, palpites, resultados e pontuações durante toda a execução da plataforma.

## RNF03 — Disponibilidade

O sistema deverá permanecer disponível aos usuários durante toda a duração das ligas, permitindo o acesso às informações, palpites, rankings e demais funcionalidades da plataforma.

## RNF04 — Rastreabilidade

O sistema deverá registrar as operações realizadas pelos usuários relacionadas às ligas, palpites, pagamentos, alterações administrativas e solicitações financeiras, mantendo um histórico para consulta e auditoria.

## RNF05 — Consistência dos dados

O sistema deverá garantir que as informações apresentadas aos usuários sejam consistentes entre as diferentes funcionalidades da plataforma, mantendo sincronizados dados de participantes, palpites, resultados, pontuações, rankings e valores financeiros.
